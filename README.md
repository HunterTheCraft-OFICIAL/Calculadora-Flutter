# Calculadora Flutter

## Objetivo

Este projeto cria um aplicativo de calculadora simples usando o Flutter.

## Funcionalidades

* Adição, subtração, multiplicação e divisão.
* Exibição do resultado em tempo real.
* Botão "CLEAR" para limpar a entrada.

## Tecnologias

* Flutter
* Dart
